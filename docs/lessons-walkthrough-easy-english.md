# FableCode: Easy-English Walkthrough (All 65 Lessons)

This is a plain-English guide you can read out loud while teaching.
Each lesson includes: goal, quick steps, common trouble signs, and pre-scripted Q&A.

## Simple word swaps (for beginners)
- API: app connection
- Contract: agreement
- Integration: connecting parts
- Production: real-world use
- Architecture: big-picture plan
- Orchestration: step control
- Fallback: backup path

## How to use this guide
1. Read the Goal line first.
2. Walk through the 4 steps in order.
3. Use the Quick Check before moving on.
4. Use the Scripted Q&A when learners ask questions.

Goal (plain English):
Understand the big idea and explain it in one sentence.

Coach note: keep this high-level. Explain the idea first, then show one simple example.

2. Make one small change related to this lesson goal.
3. Observe exactly what changed in the preview/output.
4. Repeat with one opposite change and compare results.

If it breaks:
1. Undo to last working state.
2. Change only one value at a time.
3. Re-test and narrate what changed.

Quick Check:

A: The point is to learn one core behavior so you can control it on purpose, not by guesswork.

A: Start by finding the main value shown in the lesson and changing it once.

Q: How do I know I got it right?
A: If one intentional change creates one predictable output change, you got it right.

Q: What if my result does not match?
A: Isolate one setting, compare expected vs actual, then fix the mismatch before adding complexity.
